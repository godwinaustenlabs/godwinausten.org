# Plates

Photographs supplied by the owner, used full-bleed on ink.

They live here rather than in `public/assets/photo/` on purpose: that folder's
credits file (`docs/photo-credits.md`) is generated by `npm run gen:photos` and
states that **every** file in it is an Unsplash photograph with a named
photographer. These are not, so putting them there would have made a generated
guarantee false.

| File            | Used by                                   |
| --------------- | ----------------------------------------- |
| `motion.jpg`    | `figure-plates` on `/` — the band         |
| `presence.jpg`  | `figure-plates` on `/` — the band         |
| `emergence.jpg` | `figure-plates` on `/` — the tall column  |
| `globe.jpg`     | `charter` on `/about` — beside the claim  |
| `hands.png`     | `charter` on `/about` — under the lit run |

**Provenance is unrecorded and licensing is unreviewed.** They were pasted into
the repository by the owner on 2026-09-27 with no source given. That is fine for
development and it is _not_ cleared for a public launch on that basis — it is the
same open item as `public/assets/figure.svg` (`docs/adr/0004`) and the Unsplash
set, and it is tracked with them in `SECURITY.md` §10.

All five want a black or near-black ground: they are placed as full-bleed cells
or as backdrops on `--color-ink`, and an image with a pale edge would draw a
visible rectangle against it.
